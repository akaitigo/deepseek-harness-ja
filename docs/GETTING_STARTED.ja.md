# はじめてのDeepSeek Harness

「何をするアプリなのか分からない」「英語の設定が難しい」という方向けの短い案内です。DeepSeek Harness 0.2.0-rc.2 を基準にしています。設定名や機能は更新で変わることがあります。

## 1. 何ができる？

DeepSeek Harness（DSH）は、AIに作業を依頼するためのアプリです。AIは必要に応じて「道具」を使い、指定したフォルダのファイルを読んだり、書き換えたり、コマンドを実行したりします。

例えば、以下のように頼めます。

- 「このプロジェクトが何をするものか、日本語で説明して」
- 「このフォルダのメモを読んで、決まったことと未解決のことを整理して」
- 「このコードのエラーを調べて。まず原因を説明してから修正して」

使える道具やモデルは設定・モード・プラグインによって異なります。AIの回答が必ず正しいとは限らないので、重要な結果は確認してください。

## 2. 最初に必要なもの

### AIの接続先

DeepSeek Harnessは、画面を開くだけであらゆるAIモデルが無料で使えるわけではありません。アカウントやAPIキーなど、使用するサービスに必要な接続設定を行います。

すでにAIと会話できているなら、この設定は済んでいるので変更する必要はありません。モデルの利用料金・契約・制限は、接続先のサービスによって異なります。APIキーをチャットやGitHubのIssueに貼らないでください。

### ワークスペース

**ワークスペース＝AIに作業してもらうフォルダ**です。最初は、重要なファイルが入っていない練習用フォルダを選ぶと安心です。

初回からホームフォルダ全体や、大切な資料・認証情報を含むフォルダを選ばないことをおすすめします。

### モードと権限

- **標準モード**：一般的な作業用。最初はここから始めます。
- **Creatorモード**：DSH自体の機能やプラグインを作るためのモード。普段の作業には必須ではありません。
- **権限**：ファイル変更やコマンド実行の許可範囲です。最初は作業フォルダ内の書き込みと、必要な操作ごとの確認を使います。

**フルアクセスは、慣れていないうちは選ばないでください。** 強い権限を与えると、作業フォルダ外への変更なども可能になります。OSや外部サービスの安全を保証する機能ではありません。

## 3. まず一度、頼んでみる

1. 練習用のワークスペースを選びます。
2. 新しいタスク／セッションを開き、標準モードを選びます。
3. 入力欄に以下のように書いて送ります。

   > このフォルダ用の短いREADMEを、日本語で作ってください。ファイルを作る前に、何を作るか説明してください。外部通信やコマンド実行は不要です。

4. AIが説明・作業を進めます。操作の承認が出たら、何を実行するのか読んでから許可します。
5. 作られたファイルを開き、内容を確認します。

承認画面で分からないコマンドが出たときは、許可せず「この操作の目的と危険性を日本語で説明して」と聞いて構いません。

## 4. 頼み方のコツ

次の4点があると、AIが迷いにくくなります。

| 伝えること | 例 |
| --- | --- |
| 目的 | 「メモの内容を整理したい」 |
| 対象 | 「このフォルダのMarkdownファイル」 |
| 出力 | 「要点を日本語で、見出しと箇条書きにする」 |
| してほしくないこと | 「元のファイルは変更しない。外部通信しない」 |

ファイルの指定には `@`、コマンドの一覧には `/` が使われます。まずは普通の文章だけでも依頼できます。

## 5. よく出る言葉

| 用語 | 意味 |
| --- | --- |
| モデル | 作業を考えるAIの種類 |
| エージェント | 道具を使って作業を進めるAI |
| セッション | 一つの会話・作業のまとまり |
| ワークスペース | 作業対象のフォルダ |
| ツール | ファイル読み書き、検索、コマンド実行などの道具 |
| 承認 | 危険性や許可範囲を確認して操作を許すこと |
| 計画 | 実作業の前に進め方を相談する機能 |
| 目標 | 長い作業の目的を保持し、継続して進める機能 |
| サブエージェント | 別のAIに一部分の作業を分担させる機能 |
| プラグイン | アプリに機能を追加する拡張 |
| 利用枠 | 接続先サービスの使用量や制限 |

全部を覚える必要はありません。まずは「フォルダを選ぶ → 日本語で頼む → 操作を確認する → 結果を見る」だけで十分です。

## 6. 止めたい・困ったとき

- 実行を止めたい：入力欄付近の停止ボタンを使います。すでに完了したファイル変更まで自動で元に戻るわけではありません。
- 勝手に変更してほしくない：「調査と説明だけ。ファイルは変更しないで」と最初に書きます。権限設定も併せて絞ってください。
- 大切なコードを編集する：先にGitでコミットするかバックアップを取ります。
- 英語の返答が出る：「日本語で答えて」と依頼します。このパックは画面の翻訳であり、AIの返答の言語を強制しません。
- プラグインの不具合を報告する：個人情報、認証情報、会話全文が写ったスクリーンショットをそのまま公開しないでください。
