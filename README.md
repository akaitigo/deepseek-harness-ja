# DeepSeek Harness 日本語パック

**DeepSeek Harnessを日本語で使うための、個人開発・非公式の言語プラグインです。**

設定やボタンの意味が分からず、使い始めにくい人向けに、画面の文言を日本語にします。アプリ本体を改造せず、標準の言語プラグインAPIを使います。

- **3,177件／57名前空間**のUI文言を翻訳
- 設定、チャット、入力欄、ワークスペース、ファイル表示、承認、計画、目標などに対応
- Codex Subscription 2.5.9 のUI文言も収録（同プラグインの導入は不要・別途任意）
- 未翻訳の新しい文言は英語にフォールバック
- インストール後の言語選択はユーザーが行い、モデル・認証・権限・会話履歴は変更しない

DeepSeek、WSL043、OpenAIとは無関係で、各社・作者の公式サポートや承認を受けた製品ではありません。アプリのロゴ・画像は配布していません。

## そもそもDeepSeek Harnessとは？

AIに文章で作業を頼み、ファイルの読み書きやコマンド実行などの道具を使って、PC上の作業を進めてもらうアプリです。単に会話するだけでなく、「このフォルダの資料を整理して」「このコードの不具合を直して」といった依頼に使えます。

AIが使えるモデルやサービスは、アカウント・APIキー・追加プラグインの設定により変わります。この日本語パックだけで、AIの利用契約や認証が追加されるわけではありません。

まず使い方を知りたい方は、[はじめてのDeepSeek Harness（日本語）](<docs/GETTING_STARTED.ja.md>)を読んでください。

## インストール（アプリ画面から・おすすめ）

1. DeepSeek Harnessを開きます。
2. 左側の **Plugins（プラグイン）** を開き、**Add plugin（プラグインを追加）** を選びます。
3. パッケージ名・アドレス欄に以下を入力します。

   ```text
   git+https://github.com/akaitigo/deepseek-harness-ja.git#v0.1.0
   ```

4. 内容と配布元を確認し、**Install（インストール）** を選びます。
5. 必要なら画面を再読み込みします。アプリ終了・再起動が必要と案内された場合は、実行中のタスクを完了してから行ってください。
6. **Settings → General → Language** を開き、**日本語** を選びます。

このパックは実行時の追加ライブラリやパッケージのインストールフックを持ちません。アプリのプラグインは一般に強い権限で動くため、配布元を確認して導入してください。

### Gitの取得が難しい場合

[リリース](<https://github.com/akaitigo/deepseek-harness-ja/releases>)の配布用パッケージを使えます。同じ追加欄に以下のURLを指定してください。

```text
https://github.com/akaitigo/deepseek-harness-ja/releases/download/v0.1.0/dsh-locale-ja-0.1.0.tgz
```

npmレジストリには公開していません。パッケージ名 `dsh-locale-ja` だけではインストールできない場合があります。

## 日本語にならない場合

- 「Settings → General → Language」に「日本語」があるか確認し、選択してください。
- 「Plugins」でこのパックが有効になっているか確認してください。
- 画面を再読み込みしてください。再起動が必要な場合は、作業中のタスクを止めずに済むタイミングで行ってください。
- 別の日本語パックがある場合は、そちらを優先して、このパックは何も上書きしません。
- 対象バージョンと違う場合は、[Issue](<https://github.com/akaitigo/deepseek-harness-ja/issues>)にアプリのバージョンを添えて報告してください。APIキー、アカウント情報、会話全文、個人ファイルのパスは投稿しないでください。

## 翻訳しない部分

- macOSなどのネイティブなアプリメニューや更新・終了ダイアログ
- モデルが生成する返答、ログ、他の外部プラグイン固有の文言
- 英語のオンボーディング画像、スプレッドシート内部エンジンの一部

周辺UIは日本語化しますが、存在しない日本語素材・エンジン辞書は指定しません。AIの返答を日本語にしたい場合は、依頼文に「日本語で答えて」と書いてください。

## 元に戻す・アンインストール

表示だけ戻す場合は **設定 → 一般 → 言語 → English** を選びます。
削除する場合は、先に言語をEnglishへ戻し、**プラグイン**でこのパックを無効化またはアンインストールします。

以前このPC向けに手動導入した `dsh-locale-ja-local` がある場合は、二つを同時に有効にしないでください。手動版の無効化は、その導入時の説明に従ってください。この公開版が手動版や他の設定を勝手に削除することはありません。

## 翻訳の修正・開発

翻訳は[日本語辞書](<locale/ja.json>)、照合用の元文言は[英語カタログ](<source/en.json>)にあります。

```sh
git clone https://github.com/akaitigo/deepseek-harness-ja.git
cd deepseek-harness-ja
npm ci --ignore-scripts
npm run build
npm run check
```

開発用依存として、公開済みの `@deepseek-ai/dsh-client-locale@0.2.0-rc.2` を使います。テストはその実際の言語ランタイムに全翻訳を登録し、言語切替・保存・フォールバック・取り外し・変数の整合性を確認します。実際のアプリ画面の自動E2Eテストではありません。

インストール時にビルドは不要です。[配布用クライアントバンドル](<lib/client.js>)はリポジトリに含め、ソースから再生成した結果との一致をCIで確認します。
